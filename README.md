# Java Day 35 - Product of Array Elements

## Description
This program calculates the product of all elements in an integer array using a for loop.

## Code
The program multiplies each array element and stores the result in the `product` variable.

## Example
**Input:**
`{2, 3, 4, 5}`

**Output:**
`Product = 120`

## Concepts Used
- Java Arrays
- For Loop
- Array Length
- Multiplication

## How to Run
1. Save the code in `Main.java`.
2. Compile using `javac Main.java`.
3. Run using `java Main`.
